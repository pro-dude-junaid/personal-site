# Personal Website

	A place for hosting all the stuff that I do.

## Features
	1. Showcases all my released music.
	2. Showcases all my photography.
	3. Showcases all my cinematography.
	4. Personal Vlogging.


## Important Information
	For profile picture use square crop, minimum 400x400px, ideally 800x800px
	For photography grid use images roughly at 4:3 or 3:2.
	Keep 1200x900px minimum, ideally 1600x1200px for retina screens
	Keep each file under ~300-400KB (export as JPG at ~80% quality, or WebP).
	For YouTube thumbnail shape use the usual 1280x720px (16:9) aspect ratio.

## Don't upload portrait or square images into these slots — cover will crop hard into the sides or top/bottom, which can cut off faces or key details.
